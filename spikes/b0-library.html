B0専用の試験画面です。YouTube動画のコマ送りはこの画面では行えません。B1は別の Safari動画コマ送り検証 です。

Googleの読み取り専用APIで、自分のYouTubeチャンネルにアップロードした限定公開動画をサムネイル・題名・投稿日付きで一覧化できるか試します。

1. まず安全なデモで画面確認

モック2件だけを表示します。本人のYouTube APIや認可は使用しません。ただしページ表示時、Google公式の認証用JavaScriptをGoogleから読み込みます。

JavaScript未起動。この画面が変わらない場合はSafariで開いてください。

2. 本人アカウントのYouTube動画を取得（任意）

Google CloudにてWebアプリケーション用OAuth 2.0クライアントIDを新規作成し、Authorized JavaScript originsに https://sashundev.github.io を登録した場合だけ利用してください。本人専用の継続利用アプリとしてOAuthをExternal / In productionにする場合、テストユーザー登録は不要です（未確認アプリの警告が出る場合があります）。

この検証ではYouTube Data API v3を有効にする必要があります。Google Cloudの請求先アカウントや有料枠の登録は要求しません。クォータと料金設定は利用前に確認してください。 Google Cloud・OAuthの設定手順を見る。

クライアントシークレット、Googleパスワード、APIキー、アクセストークンは入力しないでください。ページ・URL・GitHubに保存しません。

OAuth権限は youtube.readonly のみ。アクセストークンはこのタブのメモリだけに保持し、動画のダウンロード・ファイル送信・ブラウザ永続保存・ChatGPT送信は行いません。本人が明示操作した場合だけ接続します。この検証画面のデータ取扱説明／YouTube利用規約／APIポリシー

権限取り消しはGoogle側の許可も削除します。接続だけ終了する場合は「一覧・接続を消去」を利用してください。Googleアカウント側でも管理可能
