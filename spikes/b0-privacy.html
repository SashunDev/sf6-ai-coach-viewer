SF6 B0限定公開動画一覧 — データ取扱説明

本ページは本人が管理するYouTube動画一覧を取得できるかを確認するための個人用・検証段階のWebページです。商用サービスや、動画をChatGPTに直接送るアプリではありません。

取得対象・利用目的

Google OAuth 2.0で本人が明示的に許可した場合だけ、YouTube Data API v3のyoutube.readonlyを利用して、本人のチャンネルのアップロード済み動画ID・動画タイトル・サムネイル・投稿日時・公開状態を取得します。限定公開の動画だけを一覧表示します。公開・非公開の動画は一覧に表示しません。

保存・通信

OAuthアクセストークンと動画一覧は開いているブラウザのメモリに限って扱います。ブラウザのlocalStorage、sessionStorage、Cookie、サーバー、GitHubリポジトリには保存しません。Googleの認証基盤とYouTube Data APIへの通信、YouTube公式サムネイルの表示は発生します。この検証ページ独自のサーバーや解析サービスへ個人動画データを送信しません。

「一覧・接続を消去」で表示中の一覧とページ内トークンを消去します。「Google側の権限を取り消す」でGoogleの認可自体の取消も要求できます。Google側の接続管理はGoogleアカウントの接続済みアプリから確認・取り消しできます。Google側の同意履歴などはGoogleの規約に従って管理されます。

デモ・閲覧先

認証不要のモック表示では合成データだけを用い、Google APIへ一覧取得のアクセスを行いません。実アカウント表示時の動画リンクはYouTube公式サイトを開きます。YouTube動画の自動ダウンロードや保存、埋め込み動画のコマ送りは行いません。

範囲と注意

このページは個人の技術検証用です。外部利用者向けの商用提供やGoogle OAuth審査の完了を示すものではありません。使用前に本人のGoogle Cloud OAuth・APIクォータ・課金設定・YouTubeの規約を確認してください。
